# Housie Ka King Roadmap

Housie Ka King currently focuses on hosting a 90-ball game from an iPhone or iPad. The caller, spoken announcements, board and draw history, and TV controls are in the app today. Google Cast uses a separately hosted receiver.

| Priority | Work to explore |
| --- | --- |
| Contributor onboarding | Add genuine screenshots and document the simulator setup from a fresh checkout. |
| iPad accessibility | Try the caller controls with VoiceOver and larger text in portrait and landscape. Turn reproducible findings into small fixes. |
| Game-rule coverage | Add deterministic tests for prize boundaries and other edge cases in the core Swift package. |
| TV compatibility | Document real AirPlay and Google Cast sessions, including device models and any limitations. |

Future ideas include more announcement languages and bringing ticket or prize workflows from the core library into the app. These are proposals with no scheduled release. See the [issue tracker](https://github.com/Hari-Aditya-003/housie/issues) for current work, or open an issue with the use case you’d like to support.
